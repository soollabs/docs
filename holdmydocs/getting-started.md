Get HMD running and write your first pages.

## Hosting HMD yourself

1. [[Install HMD]]: start a local instance with Docker or a binary.
2. [[First-Run Setup]]: name your wiki and create a namespace.
3. [[Your First Wiki]]: build two linked pages and view their history.

Add a Git remote, public access or an AI assistant only after you have tried writing locally.

## Using an HMD someone else set up

Ask for the wiki address and a writable namespace, sign in, then go to [[Your First Wiki]]. Writing in the browser needs no install and no Git.
