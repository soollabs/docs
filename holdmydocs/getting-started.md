Get HMD running, create your first pages, and learn how the wiki fits together.

## If you're hosting HMD yourself

1. [[Install HMD]] — start a local instance with Docker or a binary.
2. [[First-Run Setup]] — name your wiki and create a namespace for your pages.
3. [[Your First Wiki]] — build two linked pages and explore their history.

Start locally. Add a Git remote, public access, or an AI assistant after you've tried the basic writing workflow.

## If someone has already set up HMD for you

Ask for the wiki address and a writable namespace, sign in, and go straight to [[Your First Wiki]]. You do not need to install software or configure Git to write in the browser.

## Understand the basics

[[HMD Concepts]] explains pages, namespaces, Markdown, and the difference between your live wiki and a static website. [[FAQ]] covers common questions about hosting, search, collaboration, and storage.

## When you're ready to share

Read [[Authentication And Access]] before inviting other people, and [[Reverse Proxies]] before exposing a local instance to the internet. If you only want to publish documentation for readers, follow [[Static Export]].

Already running HMD? Use [[Upgrade HMD]] for the upgrade checklist.
