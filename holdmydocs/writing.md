Everything you write in HMD becomes a Markdown file with a revision history. These guides cover the everyday workflow in the browser; no Git commands are required.

New to the editor? Start with [[Your First Wiki]] for a worked example.

## Write and revise

- [[Pages]] — create a page, change its path, review history, and restore an older version. Learn what happens when two people edit at once.
- [[Markdown And The Editor]] — format text, insert tables and links, and draw Mermaid diagrams with a live preview.
- [[Attachments]] — upload images and files, link to them, and understand which documents can be searched.

## Make information easy to find

- [[Links And Navigation]] — connect pages with wiki-links, browse the page tree, and find related work with tags, backlinks, and search.
- [[Namespaces]] — separate projects or audiences and give each area its own homepage, page order, and appearance.

## Share your work

A public namespace lets visitors read pages in your running HMD instance. [[Authentication And Access]] explains who can see and edit what.

For a standalone documentation website, use [[Static Export]]. Review the namespace's pages and attachments before publishing: the copy does not inherit your live wiki's access controls.
